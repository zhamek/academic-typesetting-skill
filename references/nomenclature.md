# 生物学命名与序列的排印

基因/蛋白写错正斜体，是评审一眼就能挑出来的硬伤。这里只管"怎么印"，不管"该叫什么"。

## 1 正斜体对照

| 类型 | 格式 | 示例 | 备注 |
| --- | --- | --- | --- |
| 基因符号 | **斜体** | *Cas9*、*TP53*、*CYP71AV1*、*PEX10* | markdown `*...*` |
| 蛋白符号 | 正体 | Cas9、TP53、CYP71AV1 | 与基因同名时靠正斜体区分 |
| 物种学名 | **斜体** | *Escherichia coli*、*Yarrowia lipolytica* | 属名首字母大写，种名小写 |
| 属名缩写 | **斜体** | *E. coli*、*N. benthamiana* | 首次出现给全名 |
| mRNA / cDNA / sgRNA | 正体 | mRNA、cDNA | 作为通用名词时不斜体 |
| 具体 RNA 名 | **斜体** | *pegRNA*、*gRNA* 作为命名时 | 各家略有出入，全文统一即可 |
| 限制酶 | 正体 | EcoRI、HindIII、BsaI | 三个字母斜体 + 罗马数字正体的严格写法少见，统一用正体即可 |
| 蛋白结构域 | 正体 | KRAB、PAM | — |
| 突变（蛋白） | 正体，HGVS | p.Gly12Val、p.G12V | 不斜体 |
| 突变（cDNA） | 正体，HGVS | c.35G>A | 不斜体 |
| 质粒名 | 正体 | pET-28a、pUC19 | 首字母小写 p |

**在原始 LaTeX 块里**（表格、题注）markdown 斜体不生效，必须写 `\textit{PEX10}`。

## 2 核酸 / 氨基酸序列

- 一律等宽字体（`\texttt{}` 或 markdown 反引号），不参与两端对齐。
- 方向标注：`5'-...-3'`，引号用直撇号，不要用中文引号。
- **分组问题**：v1 要求在每 10 个碱基插一个 U+2009 细空格。这会把序列本身改坏——
  读者复制出去就是带隐藏字符的串，贴进 SnapGene 直接报错。除非期刊明确要求，
  否则**不要插入任何字符**，改用"允许断行"：

```latex
% PDF：在每 10 个碱基后允许换行，不插入可见字符
\seqsplit{ATGCGATGCCGATGCATCGATCGAT}
% 或手工放置断行点
ATGCGATGCC\allowbreak GATGCATCGA\allowbreak TCGAT
```

- Word 里用"允许西文在单词中间换行"或直接让等宽段落不换行、超长时改小字号。
- 引物表里的序列列：等宽 + 右不齐 + 允许断行，不要两端对齐（会把碱基间距拉散）。

## 3 化学式与量纲

- 化学式：`$\ce{Ca(NO3)2.4H2O}$`（PDF 走 mhchem；DOCX/PPTX 靠 lua 过滤器转 Unicode）。
- 量：`\qty{1.5}{\milli\mole\per\litre}`；不确定单位宏时用字面量 `\qty{1.5}{mmol/L}` 最稳。
- 单位正体、数值与单位之间留空：`135 g/L`，不写 `135g/L`。
- 浓度不要用 `M`：写 `mol/L` 或 `mmol/L`，避免与摩尔质量混淆。

## 4 一致性检查（人工，脚本查不了）

- 同一个基因在正文、表格、图注里写法是否一致（*PEX10* vs PEX10 vs pex10）。
- 中文名与拉丁名首次出现是否成对给出，之后是否只用一个。
- 缩写首次出现是否有全称。
- 单位全文是否统一（g/L 与 g·L⁻¹ 不要混用）。
