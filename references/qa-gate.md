# 交付闸：量什么、阈值多少、失败怎么修

排版是"改了 A 坏 B"的耦合系统：挪一段文字，表 1 就可能掉页留出 8cm 空洞；缩一行，参考文献就多出一页。
所以每次改完都要重跑量测，而不是靠眼睛扫一遍 `.tex`。

## 1 命令

```bash
python scripts/contact_sheet.py output/report.pdf      # 全部页面拼一张图，看留白和掉页
python scripts/qa_pdf.py output/report.pdf --lang zh   # 硬指标
```

`qa_pdf.py` 输出 `PASS` / `WARN` / `FAIL`，有 FAIL 时退出码为 1。
`WARN` 需要人判断——比如参考文献最后一页偏短，是正常的。

## 2 检查项

| 检查 | 阈值 | 失败意味着 | 怎么修 |
| --- | --- | --- | --- |
| 页面几何 | A4 或 Letter，±3pt | 纸张混用 | `-V papersize=a4` + `geometry` |
| 字体全部嵌入 | 每个字体名带子集前缀 `ABCDEF+` | 评审机缺字变方框 | 不要用系统里没有的字体；确认 `\setmainfont` 与 `\setCJKmainfont` 都指向实装字体 |
| 无回退字体 | 不出现 DejaVu / LatinModernMath / Nimbus | 图里用了 mathtext，或正文用了 `$>$` 这类"假符号" | 见 `figures.md` 与 `latex-pdf.md` |
| 声明字体确实存在 | 指定字体族至少各出现一次 | 设了但没生效（被模板覆盖） | 检查加载顺序：header 在后、模板变量在前 |
| 页填充率 | 非末页 ≥ 85% 版心高 | 浮动体掉页，本页留洞 | 表格改 `[!t]`；或把导语挪到表后 |
| 内容不越界 | 左右不超出边距 +3pt | 表格列宽超、图过宽 | 重算列宽；图加 `width=\linewidth` |
| 无位图 | `page.get_images()` 为空 | 图被导出成 PNG，或截图贴进来 | 改 PDF/SVG；确需位图则 ≥ 300dpi |
| 编号连续 | 表/图各自 1..n 不跳号 | 手写编号漏改 | 改用 `\label`/`\ref` 或 `@tbl-` |
| 无未解析引用 | 不出现 `??` `[@` `**` `undefined` | 编译次数不够 / 语法写错 | 连编两次；检查方括号 |
| 元数据 | title + author 非空 | PDF 属性是空的 | `\hypersetup{pdftitle=...,pdfauthor=...}` |
| 日志溢出 | 见下方 | 局部排版崩 | 见 `latex-pdf.md` §8 |

## 3 版面问题诊断顺序

1. **先看联系表**（`contact_sheet.py` 的产物）。一屏看完所有页，空洞、孤行、图题错位一眼可见。
2. **再看日志**：`Overfull` / `Float too large` / `undefined` 三类，其余可忽略。
3. **最后看具体页**：把可疑页单独渲染 130dpi 放大看。

先看联系表再翻单页，比逐页翻快一个数量级。

## 4 什么不算缺陷

- 最后一页只到一半——正文自然结束，正常。
- 图/表落在页顶，上一页正文在段中断开——LaTeX 浮动的正常行为，只要断开处不是半句话。
- 参考文献 8pt——相对 11pt 正文偏小，但列表本身就该小一号。

## 5 交付清单

- [ ] `qa_pdf.py` 无 FAIL
- [ ] 联系表里没有 > 15% 的空白页（末页除外）
- [ ] 每个图/表在正文里都被引用过，编号与题注一致
- [ ] 页眉页脚每页都对，首页按约定不显示
- [ ] 摘要/关键词/标题作者单位齐全
- [ ] 参考文献条目数 = 正文引用数（没有"列了不引"或"引了不列"）
- [ ] 文件名符合约定（例：`姓名 学号.pdf`）
- [ ] 打开一次确认没有空白页、没有半个表
